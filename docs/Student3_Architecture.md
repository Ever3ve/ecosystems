# Архітектура Ecosystems Calculator

## Огляд

Застосунок є консольним калькулятором на C# (.NET 9). Кожна математична операція винесена в окремий статичний клас, а `Program.cs` відповідає лише за меню та введення-виведення.

## Компоненти

| Файл                | Клас             | Відповідальність                  |
| ------------------- | ---------------- | --------------------------------- |
| `Program.cs`        | `Program`        | Меню, ввід чисел, виклик операцій |
| `Addition.cs`       | `Addition`       | Додавання                         |
| `Subtraction.cs`    | `Subtraction`    | Віднімання                        |
| `Multiplication.cs` | `Multiplication` | Множення                          |
| `Division.cs`       | `Division`       | Ділення з перевіркою нуля         |
| `Power.cs`          | `Power`          | Піднесення до степеня             |
| `Remainder.cs`      | `Remainder`      | Остача від ділення                |
| `Percentage.cs`     | `Percentage`     | Обчислення відсотка від числа     |
| `Factorial.cs`      | `Factorial`      | Факторіал цілого числа            |
| `SquareRoot.cs`     | `SquareRoot`     | Корінь із валідацією аргументів   |

## Потік даних

1. `Program` показує меню та зчитує вибір користувача.
2. Користувач вводить два числа.
3. За вибором викликається метод відповідного класу.
4. Результат виводиться в консоль, після чого програма повертається до меню.

## Принципи проєктування

- Один клас відповідає за одну операцію.
- Класи операцій не залежать один від одного та від консолі.
- Некоректні вхідні дані дають виняток (`DivideByZeroException`, `ArgumentException`).
