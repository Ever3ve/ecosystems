# Посібник користувача Ecosystems Calculator

## 1. Призначення

Ecosystems Calculator — консольний застосунок на C# для виконання математичних операцій.

## 2. Доступні операції

Калькулятор містить реалізації таких операцій:

- додавання;
- віднімання;
- множення;
- ділення;
- обчислення остачі від ділення;
- піднесення до степеня;
- обчислення квадратного кореня.

## 3. Вимоги до запуску

Для роботи застосунку потрібен .NET SDK, сумісний із цільовою платформою .NET 9.

Перевірити встановлену версію SDK можна командою:

```bash
dotnet --version
```

## 4. Запуск застосунку

1. Відкрийте термінал у каталозі проєкту.
2. Відновіть залежності:

   ```bash
   dotnet restore ecosystems.sln
   ```

3. Запустіть застосунок:

   ```bash
   dotnet run --project ecosystems.csproj
   ```

4. Дотримуйтеся інструкцій, які відображаються в консолі.

## 5. Особливості використання

- Для ділення не використовуйте нуль як дільник.
- Для обчислення квадратного кореня використовуйте допустиме для реалізації значення аргументу.
- Перевіряйте введені дані перед виконанням обчислень.

Конкретна поведінка при некоректному введенні залежить від реалізації програми.

## 6. Збірка проєкту

Для перевірки компіляції виконайте:

```bash
dotnet build ecosystems.sln
```

Якщо збірка завершилася успішно, проєкт скомпільовано без помилок.

## 7. Додаткова інформація

Загальний опис проєкту та інструкції зі встановлення наведено у файлі `README.md` у корені репозиторію.
