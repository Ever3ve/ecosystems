# Документація API калькулятора

## Огляд

Цей документ описує основні операції калькулятора. Програма призначена для виконання базових арифметичних обчислень над числовими значеннями, введеними користувачем.

## Підтримувані операції

| Операція | Опис | Приклад |
|---|---|---|
| Додавання | Додає два числа | `2 + 3 = 5` |
| Віднімання | Віднімає друге число від першого | `5 - 2 = 3` |
| Множення | Множить два числа | `4 * 3 = 12` |
| Ділення | Ділить перше число на друге | `10 / 2 = 5` |

## Вхідні дані

Калькулятор приймає числові значення та арифметичну операцію, яку потрібно виконати.

## Результат

Програма повертає результат вибраної арифметичної операції.

## Обробка помилок

Ділення на нуль вважається некоректною операцією. Програма повинна повідомляти користувача про помилку замість повернення неправильного результату.

## Обмеження

Калькулятор підтримує лише ті арифметичні операції, які реалізовані в поточній версії програми.
