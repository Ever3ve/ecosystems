# ADR 0001: Використання ліцензії MIT

## Status

Proposed

## Context

Проєкту Ecosystems Calculator потрібна ліцензія, яка визначатиме умови використання, копіювання, модифікації та поширення вихідного коду.

Команда має обрати ліцензію, яка підходить для навчального проєкту та не створює надмірних обмежень для користувачів.

## Decision

Запропоновано використовувати ліцензію MIT.

Вона дозволяє використовувати, копіювати, змінювати та поширювати програмне забезпечення за умови збереження повідомлення про авторські права й тексту ліцензії.

Рішення набуде статусу Accepted після погодження командою.

## Consequences

Позитивні наслідки:

- прості умови використання коду;
- можливість модифікації та поширення програмного забезпечення;
- зрозумілі правила використання для інших розробників.

Можливі обмеження:

- ліцензія не надає гарантій щодо роботи програмного забезпечення;
- необхідно зберігати текст ліцензії та повідомлення про авторські права;
- остаточний вибір має бути погоджений командою.
