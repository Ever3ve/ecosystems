## Опис проєкту

**Ecosystems Calculator** — навчальний консольний калькулятор, розроблений мовою C# із використанням платформи .NET 9.

Застосунок призначений для виконання математичних операцій. Код організовано в окремих класах, кожен із яких відповідає за певну операцію.

## Можливості

- Додавання.
- Віднімання.
- Множення.
- Ділення.
- Обчислення остачі від ділення.
- Піднесення до степеня.
- Обчислення квадратного кореня.

## Технології

- C#
- .NET 9
- Git
- GitHub

## Вимоги

Для запуску потрібен .NET SDK, сумісний із .NET 9.

Перевірити встановлену версію SDK можна командою:

```bash
dotnet --version
```

## Встановлення та запуск

1. Клонуйте репозиторій:

   ```bash
   git clone <URL_ВАШОГО_REPOSITORY>
   ```

2. Перейдіть у каталог проєкту:

   ```bash
   cd ecosystems
   ```

3. Відновіть залежності:

   ```bash
   dotnet restore ecosystems.sln
   ```

4. Зберіть проєкт:

   ```bash
   dotnet build ecosystems.sln
   ```

5. Запустіть застосунок:

   ```bash
   dotnet run --project ecosystems.csproj
   ```

Замініть `<URL_ВАШОГО_REPOSITORY>` на URL вашого GitHub-репозиторію.

## Структура проєкту

- `Program.cs` — точка входу та взаємодія з користувачем.
- `Addition.cs` — додавання.
- `Subtraction.cs` — віднімання.
- `Multiplication.cs` — множення.
- `Division.cs` — ділення.
- `Remainder.cs` — обчислення остачі.
- `Power.cs` — піднесення до степеня.
- `SquareRoot.cs` — обчислення квадратного кореня.
- `ecosystems.csproj` — конфігурація проєкту.
- `ecosystems.sln` — файл рішення.
